# STREET RUSH 3D — Unity Edition

Engine: Unity 6.3 LTS
Editor version: 6000.3.0f1

This is the primary Unity development project.
The original Godot project is preserved separately.

Development environment:
- GitHub Codespaces
- GitHub
- Unity Build Automation

Target platforms:
- Windows
- Android
- WebGL (subject to feature and performance compatibility)

Project structure:
- Assets/Scripts: Game systems and C# scripts
- Assets/Scenes: Game scenes
- Assets/Editor: Editor automation tools
- Packages: Unity package dependencies
- ProjectSettings: Unity project configuration
